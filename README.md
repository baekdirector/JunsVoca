# JunsVoca

초등학교 고학년~중학교 대비 영어 단어/숙어 학습을 위한 PWA 웹앱입니다.

학원 프린트물을 사진으로 찍으면 OCR로 단어와 뜻을 추출하고, 추출된 단어로
스펠링 쓰기 / 뜻 쓰기 두 가지 유형의 문제를 랜덤으로 출제합니다. 부모는
테이블 형태로 학습 이력과 정답률을 확인할 수 있습니다.

화면 디자인 시안: 이 프로젝트의 Design 아티팩트 참고.

## 현재 상태

Vite + React + TypeScript 기반 프로젝트 스캐폴딩 단계입니다. 아래 기능은
아직 구현되지 않았습니다:

- OCR 촬영/업로드 및 단어 추출 (Tesseract.js)
- 단어장 저장/편집 (IndexedDB, Dexie)
- 스펠링 쓰기 / 뜻 쓰기 퀴즈 엔진
- 부모용 결과 대시보드
- PWA 매니페스트/서비스 워커 구성

## 개발

```bash
npm install
npm run dev
```
